# Vila vista de cima

Projeto da Aula 08 de Jogos Digitais II, feito no Godot 4.7. A vila tem grama, ruas, casas, árvores, horta e um personagem que anda nas quatro direções.

## Como jogar

Abra `project.godot` no Godot e execute a cena principal com F5. Use as setas ou W, A, S e D para andar.

## Créditos

- Tileset: Tiny Town, de Kenney — https://kenney.nl/assets/tiny-town — licença CC0.
